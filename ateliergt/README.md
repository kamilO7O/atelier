# Atelier — фабрика мягкой мебели

Единый проект объединяет предыдущую версию сайта, каталог из 40 моделей и обновлённую мобильную адаптацию. Главная и каталог запускаются из одного Express-проекта.

## Стек

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database: PostgreSQL (схема подготовлена, подключение можно добавить следующим этапом)
- Authentication: JWT + HttpOnly Cookies (точка интеграции предусмотрена)
- Passwords: bcrypt (для серверной авторизации)

## Запуск

### Backend

```bash
cd server
npm install
npm run dev
```

Сайт откроется через Express:

```text
http://localhost:3000/index.html
http://localhost:3000/catalog.html
```

### Frontend

Если backend не нужен, файлы из `client/` можно открыть напрямую в браузере или запустить статическим сервером:

```bash
npx serve client
```

## Структура

```text
atelier-project/
├── client/       — интерфейс сайта и каталог
│   ├── index.html
│   └── catalog.html
├── server/       — Express-сервер и API-точки
│   ├── package.json
│   └── server.js
├── database/     — SQL-схема PostgreSQL
│   └── schema.sql
├── uploads/      — пользовательские изображения и файлы
└── README.md
```

Каталог содержит 40 моделей: по 10 диванов, кресел, кроватей и столов. Фильтры и корзина работают на стороне клиента; данные товаров сейчас находятся в `catalog.html` и готовы к переносу в PostgreSQL.

## Мобильная версия

Адаптивная верстка включена в обе страницы:

- `client/index.html` — мобильное меню, вертикальная витрина, полноэкранная корзина и форма расчёта.
- `client/catalog.html` — мобильное меню, горизонтальная прокрутка фильтров, двухколоночная сетка товаров и полноэкранная корзина.
- Проверены сценарии узких экранов 320–420 px, планшетных ширин до 900 px и отсутствие горизонтального переполнения.
